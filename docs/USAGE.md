# 本机用量口径

- 日期：本机时区，读取今天和前 30 个日历日；日按小时，本周从周一、本月从 1 日累计，排除未来事件。跨周／跨月后，失效的选中日期自动恢复为周期总量。
- 数据：只读 Claude Code 的 projects/transcripts 与 Codex sessions/archived_sessions；没有记录的任务不可恢复。网页登录本身不会产生本机用量记录。
- Claude：按 requestId + message.id 去重，后续片段替换同一消息用量。input、cache read、cache creation、output 四类互斥相加；thinking 已包含在 output 中。
- Codex：新版 token_usage_record 使用 response_id 去重，优先于同一文件镜像 token_count。旧格式按累计差值计算；第一条只计 last_token_usage，避免计入 fork 继承的历史；重复累计值不再累加。缓存输入从 inclusive input 扣除再分别计价，reasoning 已包含在 output 中。
- 更新：独立 Worker 每 30 秒增量读取追加行；未完成的 JSONL 行下次重读。重启时重新读取近期记录，不保存另一份对话内容。

## Claude / Codex 完成通知

设置中的“任务完成通知”默认开启，旧配置升级也默认开启。关闭后立即收起当前通知并清空排队通知；关闭期间的完成事件不补弹，重新开启仅提醒之后新完成的任务。开关立即保存，重启后保持；不关闭任务监测，也不消除刘海完成标记。

Claude Desktop 的 Code 会话或本机 Codex 聊天完成后，刘海向下展开通知，按「工具名称 / 会话标题 / 本轮描述」显示。点击正文任意位置打开对应会话；右上角 × 只收起通知。通知底边的细线表示剩余展示时间，5 秒后收起，鼠标悬停或键盘焦点停留在通知内时暂停计时。收起、关闭和发送跳转请求本身不会清除完成标记。对应工具实际进入前台并持续停留约 1–2 秒后，会清除该工具已有的全部完成提醒；如果一直在前台，完成后同样会清除。运行中和需要协助的状态保持不变。这是工具级提醒消除，不代表所有会话都已读，不修改 Claude / Codex 自己的已读状态。可用的具体会话已读信号仍会优先消除对应提醒。

对应工具在前台时，不弹出该工具的完成通知；在通知入队和显示之前都会检查前台应用，避免先展开再收起。被抑制的这一轮通知切走后也不补弹；另一个工具在后台完成时仍正常提醒。此规则按客户端判断，不区分同一客户端内的不同会话。

多个完成事件依次展示，同一轮只提醒一次。查看用量面板时暂缓通知；锁屏会隐藏并丢弃当前展示，关闭某个工具只清空该工具的待展示通知。启动时不会补弹历史完成记录。

接入边界：Codex 从本机线程数据库读取聊天标题，从 `task_complete.last_agent_message` 读取最多 400 字符的完成摘要，使用 `codex://threads/<id>` 跳转。读取 Claude Desktop 已有的本地完成元数据、会话标题与当前轮次 `postTurnSummary`，不读取整段对话，也不接管 macOS 通知中心。系统通知仍由 Claude 自己管理。Claude 摘要最多等待 4 秒，缺失时显示「本轮处理已结束。」；没有可验证的桌面会话 ID 时只打开 Claude 客户端。指定会话链接依赖 Claude Desktop 的 `claude-code-desktop` 路由，客户端版本变化时可能需要适配。普通 Claude 网页聊天、Cowork 和独立终端 Claude Code 的系统通知不在本次接入范围。

通知描述统一转为纯文本预览：去掉常见 Markdown 格式标记，保留链接文字和代码文字；来源、标题、描述各一行，标题和描述超宽显示省略号，不渲染 HTML。
