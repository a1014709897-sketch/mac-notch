# Mac Notch v0.2.5 体验版

本次改善刘海条的双工具入口、宽度适配和收起动画。支持 Apple Silicon / Intel，要求 macOS 13 及以上。

## 本次更新

- 同时开启 Claude 和 Codex 时，两个快捷入口持续保留，各自显示运行、等待、完成或闲置状态。一个工具执行任务不会挤掉另一个工具；只开启一个工具时保留单工具布局。
- 根据图标、额度、任务数量等实际内容计算刘海宽度，统一间距，并避让屏幕摄像头区域。
- 修正协助通知图标与正文的左侧对齐，改善通知收起时卡片和图标的过渡。
- 修复额度面板收起时突然变宽、缩小或向左跳动的问题。收起动画结束后保留原生窗口画布，透明区域允许鼠标穿透；数据刷新不再打断收起动画。
- 增加窗口生命周期检查，避免窗口已销毁后，迟到的 IPC 或定时回调继续操作窗口而弹出 JavaScript 异常。
- 官网交互演示同步双工具各自独立的状态展示。

## 下载与升级

- Apple 芯片：`Mac-Notch-0.2.5-arm64.dmg` 或对应 ZIP。
- Intel：`Mac-Notch-0.2.5-x64.dmg` 或对应 ZIP。
- 控制页可检查更新，下载并校验后打开安装包；也可退出旧版后手动替换应用，保留原有配置。
- 官网安装脚本自动识别架构并校验文件；已有同名应用时不会覆盖。

## 验证与边界

发布验证覆盖自动回归、原生窗口布局、打包应用运行、收起动画及鼠标区域。双工具入口和额度面板收起已在开发阶段人工复验。Intel 安装包经过架构与原生依赖检查及 Rosetta 运行验证；尚未完成 Intel 真机验收。

本版仍为 **ad-hoc 签名的体验版，尚未 Apple Developer ID 公证**。macOS 可能阻止首次打开；请核对本仓库来源和 SHA256SUMS.txt。
