# Mac Notch v0.2.2 体验版

Apple Silicon / Intel 均支持，要求 macOS 13 及以上。Apple 芯片下载 `Mac-Notch-0.2.2-arm64.dmg`，Intel 下载 `Mac-Notch-0.2.2-x64.dmg`。也可使用对应 ZIP，或通过官网安装命令自动选择架构。

## 本次更新

- 新增“需要协助通知”独立开关。Codex 同步、异步提问显示实际待回答的问题；部分回答后只保留剩余问题，不重新弹出或重置计时。没有正文的状态信号使用通用提示。
- 协助通知与完成通知分别控制，关闭或点击通知不会把问题标记为已回答，重新开启不补弹旧事件。旧配置原先关闭通知时，协助通知也保持关闭。
- 控制页增加两类通知的效果预览图和实际预览按钮，沿用原有深色样式。
- 新配置默认开启“刘海条空闲时显示剩余额度”，保留旧用户明确关闭的选择。
- 默认右击打开控制页，双击展开用量与额度；可一键交换两项操作并显示提示，避免手势冲突。单击仍然打开对应工具。
- 控制页新增“检查更新”：识别本机架构、下载 DMG 并验证大小及 SHA-256，再打开安装包。不会自动覆盖应用。

## 安装与升级

退出旧版 Mac Notch，打开 DMG，将应用拖入原来的应用程序目录；配置会保留。官网安装脚本适用于新安装，遇到已有同名应用不会覆盖。v0.2.1 及更早版本请从本页下载安装；v0.2.2 起可在控制页检查后续更新。

本版仍为 **ad-hoc 签名的体验版，尚未 Apple Developer ID 公证**。macOS 可能阻止首次打开；请核对本仓库下载来源及 SHA256SUMS.txt。系统若提供针对该应用的“仍要打开”，确认信任后再操作，不要关闭全局安全保护。

## 验证范围

自动检查覆盖任务状态、问题正文传递、部分回答、通知去重、设置持久化、手势交换、用量布局、版本/架构筛选、下载校验和安装脚本。Apple Silicon 原生及 Intel 包的 Rosetta 验证不等于 Intel 真机验收，仍欢迎反馈具体机型和系统版本。

提醒依赖客户端提供的本地状态，不能覆盖所有权限弹窗及远程任务。Token 和 API 费用估算来自本机记录，不是官方账单。体验版可接收体验版和正式版更新，正式版仅接收正式版更新。
