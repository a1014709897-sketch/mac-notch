# Mac Notch v0.2.4 体验版

本次改善点击刘海、菜单和通知打开 Claude / Codex 时的失败处理，减少重复提示。支持 Apple Silicon / Intel，要求 macOS 13 及以上。

## 本次更新

- 修复打开客户端时，系统拒绝启动操作可能弹出 JavaScript 主进程异常的问题，统一处理启动异常、执行失败和超时。
- 正常打开不提示。打开失败时显示“暂时没能打开 Claude / Codex”，提供手动打开客户端、退出并重新打开 Mac Notch 的简短指引，不展示错误堆栈，也不再把所有失败都说成未安装客户端。
- 同一工具正在打开时忽略重复点击；提示未关闭时不叠加，所有工具共用 30 秒提示间隔，减少连续点击带来的打扰。
- 打开失败不会被记为已查看，也不会主动清除对应通知。

## 下载与升级

- Apple 芯片：`Mac-Notch-0.2.4-arm64.dmg` 或对应 ZIP。
- Intel：`Mac-Notch-0.2.4-x64.dmg` 或对应 ZIP。
- v0.2.2 起可在控制页“检查更新”，下载并校验后打开安装包升级；也可退出旧版后手动替换应用，保留原有配置。
- 官网安装脚本自动识别架构并校验文件，适用于新安装；已有同名应用时不会覆盖。

## 验证与边界

新增回归覆盖启动被拒绝、异步失败与超时、恢复后成功、重复点击、提示限频，以及通知与已查看状态。此次修复保证已覆盖的打开失败得到妥善处理，不代表已经确认或消除每台 Mac 上的系统拒绝原因。

本版仍为 **ad-hoc 签名的体验版，尚未 Apple Developer ID 公证**。macOS 可能阻止首次打开；请核对本仓库来源和 SHA256SUMS.txt。Rosetta 验证不等于 Intel 真机验收。
