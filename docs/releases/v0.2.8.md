# Mac Notch v0.2.8 体验版

- 更新缓存只保留一份完整安装包：启动清理历史包及中断残留，新包校验成功后移除旧包，失败保留原包。
- 设置面板扩大至 520 × 820，并适配屏幕可用区域。
- 打开设置显示 Dock 图标，关闭设置后恢复后台运行。
- 空闲额度开关增加开启／关闭效果图；三个菜单栏开关下增加右上角位置示意图。

## 安装与更新

提供 Apple Silicon 和 Intel 的 DMG、ZIP，以及源码和 SHA-256 校验清单。退出旧应用后将新应用替换到原位置，再重新打开。应用内更新仍为手动下载安装包，不自动替换或重启应用。缓存清理不扫描用户下载文件夹。

当前为 ad-hoc 签名，未经 Apple Developer ID 公证。macOS 可能阻止打开；不修改系统安全设置。

## 验证范围

自动测试及本机 Electron 隔离界面回归；arm64/x64 构建与签名完整性检查。Apple Silicon 本机原生模块运行检查。Intel 未进行真机验收；Dock 点击图标的人工验收受系统辅助功能读取超时限制。
