# Mac Notch v0.1.0

首个版本：在 macOS 刘海查看 Claude / Codex 任务状态，在菜单栏查看两者订阅剩余额度。

## 功能

- Claude 橙色小怪兽、Codex 蓝紫图标，空闲常驻和运行动画。
- 固定宽度、单行无文案；悬停不展开，单击打开客户端，双击查看额度与设置。
- 单任务三个点；同工具多任务显示已完成/总数；协助轻量问号优先；全部完成显示细线勾。
- 完成项按具体会话已读信号清除，查看一个会话不会清空其他会话的提醒。
- 两个彩色菜单栏图标显示剩余百分比，面板显示额度窗口和重置时间。
- 本地只读状态采集、系统/应用专用代理、手工 Claude 网页凭据加密保存，无遥测服务器。

## 下载

- `Mac-Notch-0.1.0-arm64.dmg`：Apple Silicon Mac 安装包，macOS 13+。
- `Mac-Notch-0.1.0-arm64.zip`：同版本应用压缩包。
- `Mac-Notch-0.1.0-source.zip`：源码、文档、测试及构建配置，不含依赖和账号配置。
- `SHA256SUMS.txt`：附件校验清单。

下载后可在同一目录执行 `shasum -a 256 -c SHA256SUMS.txt` 验证文件。

## 当前边界

此版本采用 ad-hoc 签名，未完成 Apple Developer ID 公证；互联网下载后可能被 Gatekeeper 阻止。无需关闭系统安全保护，可选择自行从源码构建。首发附件仅含 Apple Silicon，Intel 尚未真机验收。

任务状态与已读识别依赖客户端本地格式；无法取得可靠已读信号时保留完成提醒。点击打开客户端，不保证定位到具体会话。额度需要厂商订阅登录，API Key 不代表订阅额度。

## 验证

16 项自动测试通过；窗口检查覆盖九种状态组合，并检查固定几何、摄像头避让和数字布局。真实 Claude / Codex 额度接口已做本机只读连通验证。完整手工验收范围见仓库 `docs/VALIDATION.md`。
