# Mac Notch v0.2.6 体验版

增加 WorkBuddy 支持，并统一三种工具在刘海条与菜单栏中的显示行为。

## 本次更新

- 支持 WorkBuddy 的本机任务、待协助状态、任务完成及多任务计数，并提供本机用量统计。
- 刘海条可在 Claude、Codex、WorkBuddy 中任选最多两个工具；菜单栏开关独立，可以同时显示三个工具。
- WorkBuddy 开启后按需发起中国版 Web 授权，完成后刷新额度；提供重新登录、取消授权和用途说明。授权凭据加密保存在 Mac Notch 自己的配置目录，不读取 Token Monitor 的账号配置。
- WorkBuddy 积分额度按服务返回的真实比例显示剩余百分比，未知状态显示“—”。
- 增加空闲、运行、等待协助、完成、多任务的角色动效。Codex 保留花瓣形外轮廓，以深色终端线条表现状态；WorkBuddy 使用白绿猫耳头部。
- 校准图标实际可见轮廓，保留各自比例；额度数字采用常规字重。
- 修复关闭刘海条中的某个工具时，其菜单栏入口也被错误隐藏的问题；菜单栏点击和额度刷新独立工作。

## 下载与升级

- Apple 芯片：`Mac-Notch-0.2.6-arm64.dmg` 或对应 ZIP。
- Intel：`Mac-Notch-0.2.6-x64.dmg` 或对应 ZIP。
- 退出旧版后替换应用，保留已有配置；也可使用控制页的手动更新入口。

## 验证与边界

发布前已通过 108 项自动测试、180 个布局与动效场景、菜单栏独立开关回归及 Apple Silicon 打包应用的完整窗口回归。两个架构的签名完整性、原生依赖与加载运行已验证；实际刘海上的五种 Codex 动效已由维护者确认。Intel 本地运行验证采用 Rosetta，不等同 Intel 真机验收。

WorkBuddy 网页授权需要用户本人完成；账号授权成功后的实际额度取决于供应商返回。费用统计属于估算，不是实际账单。

本版沿用 **ad-hoc 签名的体验版，尚未 Apple Developer ID 公证**。首次打开可能被 macOS 阻止，请核对仓库来源与 SHA256SUMS.txt。
