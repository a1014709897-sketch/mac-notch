# Mac Notch v0.2.1 体验版

面向少量用户的 Apple Silicon / Intel 内测版本，要求 macOS 13 及以上。Apple 芯片下载 `Mac-Notch-0.2.1-arm64.dmg`，Intel 下载 `Mac-Notch-0.2.1-x64.dmg`；也可使用对应应用 ZIP，或让官网安装命令自动选择。

## 本次变化

- 新增“任务完成通知”开关，默认开启、即时保存；关闭时收起通知，重新开启不补弹旧事件，刘海任务状态保留。
- Claude / Codex 完成通知显示工具、会话标题和本轮摘要，5 秒自动收起，悬停暂停；支持可用的客户端会话深链。
- 对应工具在前台时不弹出它的完成通知；持续返回工具约 1–2 秒后消除已有完成提醒，运行中和待协助状态保留，不修改客户端已读数据。
- 工具、菜单栏显示、空闲额度和登录启动设置即时保存。
- 用量面板支持日／周／月：日按小时、本周从周一、本月从 1 日统计；修复跨周／跨月后旧选中日期与总量标签不一致的问题。
- 去掉用量面板底部说明文案，保留更新时间。
- 调整刘海轮廓、图标、通知与用量面板布局；多任务计数保持字号并按需扩宽两侧。

## 安装与升级

1. 退出已运行的 Mac Notch，打开 DMG，将应用拖入应用程序目录；也可以解压应用 ZIP。
2. 命令安装使用官网 `install.sh`，固定下载此版本并验证 SHA-256、应用身份和签名完整性，安装到 `~/Applications`。已有同名应用时脚本不会覆盖，请先退出并移走旧应用，再执行安装。配置保留。
3. 打开 Mac Notch 选择工具。再次打开应用可返回设置。Claude 额度需要 Claude Code CLI 的有效订阅登录；只有桌面版登录不保证可读到额度。

**此体验版为 ad-hoc 签名，未做 Apple Developer ID 签名与公证。Gatekeeper 可能阻止打开；签名完整性校验通过不代表已通过 Apple 安全评估。** 如果系统阻止，请先核对下载来源和校验文件；确认信任后，可查看系统设置「隐私与安全性」是否提供针对该应用的「仍要打开」。若没有该选项，请反馈系统提示，勿关闭全局安全保护。

## 验证与边界

本地自动测试和 Electron 窗口冒烟检查覆盖任务状态、通知、设置持久化、用量周期、布局及安装脚本。完整记录见 `docs/VALIDATION.md`。

- 已补充 Intel（x64）二进制，使用与 v0.2.1 标签一致的应用源码构建，且该标签的 x64 CI 构建已通过；已通过本机 Rosetta 下的 x64 原生依赖与实窗检查，仍未完成 Intel 真机验收。
- 真实客户端深链、额度接口和状态协议可能随版本变化；模拟任务检查不等于另一台 Mac 上的真实任务验收。
- Token 和费用仅来自本机记录，API 费用估算不是订阅账单。
- 无自动更新；前台抑制通知按工具判断，不区分该客户端内的会话。

反馈请附 Mac 芯片、macOS 版本、Claude / Codex 版本、复现步骤和截图；请遮盖会话内容、账号和凭据。重点测试首次安装、真实任务提醒、通知跳转、日／周／月用量及关闭后重新打开设置。
