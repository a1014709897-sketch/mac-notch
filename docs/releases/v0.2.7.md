# Mac Notch v0.2.7 体验版

修正任务完成提示的保留和让位规则，避免未查看的完成状态因计时消失。

## 本次更新

- 单任务完成或所有任务完成后，完成勾持续保留，直到对应工具被持续访问或会话已读；取消未查看完成项的 24 小时清理。
- 同一工具仍有任务时，完成勾临时展示，完成满 8 秒后让位给进度，例如 1/2；让位不等于已读，不删除完成计数。
- 未查看的完成任务可与后续新增任务一起计数；启动前的历史完成仍不加入。
- 需要协助优先。正在展示或排队的完成通知保留原有保护，各工具独立处理。

## 下载与升级

Apple 芯片选择 arm64，Intel 选择 x64。退出旧版后替换应用，已有配置保留；应用内也可以手动检查更新。附件包含两种架构的 DMG / ZIP、源码 ZIP 和 SHA256SUMS.txt。

## 验证与边界

112 项自动测试通过，包含单任务保留、多任务 8 秒让位、完成计数、后续任务、通知保护和工具隔离回归。源码及 Apple Silicon 打包应用通过隔离配置的 Electron smoke。双架构签名、Electron/Koffi 架构与原生运行加载已验证；Intel 运行验证采用 Rosetta，不等同 Intel 真机验收。真实账号任务的完整人工回归未覆盖。

沿用 ad-hoc 签名，尚未 Apple Developer ID 公证。请核对发布来源与 SHA256SUMS.txt。
