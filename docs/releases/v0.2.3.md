# Mac Notch v0.2.3 体验版

本次优化完成通知与协助通知的标题和状态标记。支持 Apple Silicon / Intel，要求 macOS 13 及以上。

## 本次更新

- 两类通知统一显示会话标题：任务完成在标题后显示绿色完成勾，待协助显示金色问号，沿用刘海条的图标样式。
- 长标题截断时保留状态图标。正文继续展示本轮结果或实际待回答的问题，不以状态提示替代内容。
- 协助通知展开时，隐藏顶部任务条重复的问号，与完成通知的处理一致；通知收起后按真实任务状态恢复，关闭通知不会把问题标记为已回答。
- 补齐 Claude 待协助通知的会话标题读取，复用现有桌面元数据。取不到标题时显示“Claude 会话”或“Codex 会话”。
- 控制页的效果图和预览按钮同步采用新样式。

## 下载与升级

- Apple 芯片：`Mac-Notch-0.2.3-arm64.dmg` 或对应 ZIP。
- Intel：`Mac-Notch-0.2.3-x64.dmg` 或对应 ZIP。
- v0.2.2 起可在控制页“检查更新”，下载并校验后打开安装包升级；也可退出旧版后手动替换应用，保留原有配置。
- 官网安装脚本自动识别架构并校验文件，适用于新安装；已有同名应用时不会覆盖。

## 验证与边界

自动回归覆盖会话标题、实际正文、部分回答、状态图标、顶部标记隐藏与恢复，以及长标题截断。两种架构均进行构建与签名完整性检查；Intel 包的 Rosetta 验证不等于 Intel 真机验收。

本版仍为 **ad-hoc 签名的体验版，尚未 Apple Developer ID 公证**。macOS 可能阻止首次打开；请核对本仓库来源和 SHA256SUMS.txt，不要关闭全局安全保护。任务提醒依赖客户端提供的本地状态，无法覆盖所有权限弹窗和远程任务。
