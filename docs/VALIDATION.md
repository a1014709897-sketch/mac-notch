## 验证边界

- 本机已验证内置实体刘海；朋友的那台 Mac、外接屏切换、自动隐藏菜单栏和全屏组合还需实机复测。
- API 金额为标准费率估算，不是官方账单；未逐条与账单对账，不涵盖缺失日志、远程/网页使用、长上下文阶梯和加速费率。
- Intel 构建流程保留，当前公开二进制为 Apple Silicon；不声称完成 Intel 真机验收。
- 账号接口依赖厂商协议和有效订阅登录；CLI 启动本身不等于完成登录，应用不自动续期令牌。
