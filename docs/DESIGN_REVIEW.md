# 官网设计复盘

本轮依据：保留已有图形与刘海动画，减少无用文案和英文，面向第一次接触产品的用户整理内容，并参考 [听脑官网](https://itingnao.com/) 的信息层级与图文排布。

## 页面首先要回答什么

访客需要先知道 Mac Notch 的用途：在 Mac 顶部查看 Claude 和 Codex 的任务状态，以及订阅剩余额度。随后才需要了解操作方法和安装方式。

因此保留一条阅读顺序：**用途 → 可操作的演示 → 四项具体功能 → 安装 → 常见问题**。已经看见的效果，不再额外配一段解说；影响安装和使用判断的信息，则不能为了简洁而删掉。

## 上一版的主要问题

### 内容出现了重复

首屏、演示上方、演示下方、横向标语、功能标题和末尾下载区，都在重复描述“AI 在工作，你不用一直看着”。这些内容单独看没有明显错误，放在一起却增加了阅读距离。

本轮删除演示解说、横向标语和末尾重复宣传区。被指出的“小怪兽轻跳，Codex 旋转。三个小点告诉你，它们还在忙。”已经从 HTML 和脚本中删除，不是用样式隐藏。演示只保留状态按钮、示例任务和必要的“示例数据”标记。

### 标签抢走了正文的注意力

`JUST ENOUGH`、`MADE FOR YOUR AGENT`、栏目编号、`BETA`、大写英文装饰语没有帮助用户理解功能，反而让人不断切换语言和阅读层级。本轮删除这些内容。Mac Notch、Claude、Codex、GitHub、macOS 等名称及安装命令继续保留，它们承担产品辨认或操作用途。

### 排版缺少共同的对齐规则

旧版使用不等宽卡片、侧置说明文字、多种小字号和多处独立分隔线。主标题、卡片、安装区和 FAQ 各自成立，但纵向浏览时缺少连续的边缘与节奏。

本轮统一主要内容容器，功能卡片改为等宽两列；图形区域高度、内边距、标题与正文间距一致。栏目说明放在标题下方，不再悬在另一侧。版块之间用留白与浅色背景区分，去掉导航、标语、FAQ 和页脚的装饰性分隔线。

## 文案取舍

| 位置 | 最终处理 | 原因 |
|---|---|---|
| 首屏标题 | AI 任务进度，抬眼就知道。 | 同时交代对象和使用方式。 |
| 首屏说明 | 在 Mac 顶部查看 Claude 和 Codex 的任务状态与剩余额度。 | 直接说明支持的工具与功能。 |
| 演示状态 | 空闲、进行中、需协助、已完成 | 让画面展示效果，状态名称负责辨认。 |
| 演示下方 | 删除整段动画解说 | 用户可以直接看到动画，不需要旁白。 |
| 功能卡片 | 每张一个标题、一句说明 | 分别介绍任务状态、额度、点击操作和多任务提醒。 |
| 安装标题 | 一条命令，完成安装。 | 命令和复制按钮是主要操作。 |
| 安装细节 | 平台、版本和公证限制留在安装区；更多细节放 FAQ 或链接 | 保留会影响用户选择的信息，减少主流程的技术说明。 |
| 页脚 | 保留代码、版本、反馈与来源链接 | 不再加一组重复口号和下载大标题。 |

“看起来简洁”不能以误导为代价。示例额度不冒充真实账号数据；Apple 公证限制仍明确说明；状态识别、会话定位和提醒消除的限制继续保留在 FAQ。

## 从参考网站吸收了什么

听脑官网的首屏先给产品用途和一句说明，再给明确入口与产品展示；功能区使用稳定的容器和图文关系。本轮采用相同的阅读原则，保留 Mac Notch 自己的浅绿色调、山景、工具图标和交互演示。

Mac Notch 的功能范围更小，因此没有扩展为大型产品站，也没有增加用户评价、数据成绩或额外展示模块。参考站帮助确定层级，不能替代对本项目内容是否必要的判断。

## 当前布局规则

- 主要内容最大宽度为 1120px，导航、演示、功能、安装和 FAQ 共用左右边缘。
- 桌面功能卡片为两列，间距 24px；大屏卡片内边距 32px，图形区高度 156px，图文间距 24px。
- 桌面正文主要为 16px，栏目标题 34px；手机正文为 16px，栏目标题随屏幕调整为 27–29px。
- 标题使用适度字重，减少强制断行。小字号只用于版本、示例数据和图形内部的辅助信息。
- 主要触控按钮至少 44px 高。保留可见键盘焦点、动画暂停和系统“减少动态效果”支持。
- 手机使用单列功能卡片。安装命令自动换行，复制按钮独占一行。
- 插画自身保留景深、轻微旋转和动画；承载内容的卡片与文字保持规整。

## 实际验证

本轮浏览器检查覆盖 320、375、768、1024、1440px 五档宽度：没有横向溢出，主要区块的左右边缘一致，标题、命令与控件没有越出视口。

1440px 测量中，四张功能卡片均为 548px 宽、约 317px 高；图形区域均为 156px 高，文字距卡片顶部均为 212px。同一排的标题与正文起点一致。

十种工具与状态组合已检查：刘海宽度固定，运行时每个可见工具均有三个点，单工具保留整条点击区域。额度按钮、双击、Q 键打开面板，关闭按钮、Escape 与外部点击收起面板均正常；Escape 会返回触发按钮。复制命令反馈、FAQ 键盘操作及动画暂停正常，浏览器未报告脚本错误。

网站构建检查包含 JavaScript/Bash 语法、链接锚点和本地资源。安装脚本与已发布应用不在本轮修改范围。

上述检查确认布局与功能是否正常；文案是否合意、视觉是否舒服，仍以实际浏览体验和用户反馈为准。

## 后续逐点精简

根据页面上的七处批注，删除演示底部标记、额度和动画操作栏、首屏次要下载入口、功能区隐私说明条、安装区次要链接与公证说明，以及页脚链接组。随后按最新批注删除官网页脚来源文案，页脚仅保留品牌。页面保留安装主入口、状态与工具切换、角色动画、命令复制和 FAQ。来源、许可、公证与安装说明仍见仓库和 Release。

双击刘海和 Q 键仍可打开额度演示；系统“减少动态效果”继续生效。删除按钮对应的脚本引用和样式，同时移除空容器；演示控件在宽屏左右对齐，窄屏上下排列。前文的暂停按钮和可见额度按钮记录属于此前版本。
