# v0.2.1 产品需求与验收

## 目标和范围

面向使用 Claude Code 或 Codex 的 Mac 用户，用一个稳定的小入口回答两个问题：工具是否在工作/需要我处理？订阅还有多少额度？

包含 macOS 刘海状态、可独立开关的工具和菜单栏额度、日／周／月 Token、API 费用估算与对应趋势。无服务端、Windows/Linux、其他厂商、多设备同步。

## 交互合同

| 场景 | 展示 | 操作 / 退出条件 |
|---|---|---|
| 无任务 | Claude 左、Codex 右，轻微空闲动作 | 各侧单击打开各自客户端 |
| 单工具运行 | 左 logo、右侧三个点；Claude 间歇轻跳，Codex 旋转 | 整条单击跳转；运行状态不清除 |
| 双工具运行 | 左 Claude、右 Codex，各有自己的状态 | 各侧独立点击 |
| 同工具多任务 | 已完成/总数，例如 `1/3`；计数轻微过渡 | 按会话去重；等待协助优先问号，全完成显示勾 |
| 需要协助 | 淡金色小问号，无圆框、无文案 | 只有回答/继续执行/终止/新指令替代才能解除；点击不是回答 |
| 已完成 | 静止 logo + 薄荷绿细线勾 | 具体会话已读后清除该会话；工具持续前台约 1–2 秒后清除该工具已有的完成提醒，不修改客户端已读数据 |
| 查看额度 | 双击将刘海本身展开为用量与额度面板 | 再次双击或面板失焦收起；悬停无展开 |

收起的任务条高度保持不变，普通状态使用基础宽度，多任务计数按需扩宽两侧且保持摄像头中心不变，不显示任务文案，不增加第二行，不滚动文字。真实摄像头遮挡区域不可排字。单击延迟 350ms 用于区分双击；键盘 Enter 立即打开。

额度图标为彩色，数字为剩余百分比，取已知窗口的最小值。面板显示各窗口与重置时间。网络错误保留明确标记的历史值；无数据为 `—`。

“任务完成通知”为独立总开关，默认开启，旧配置缺少该字段时也开启；即时保存。关闭会清空当前与排队通知，重新开启不补弹旧事件，不影响刘海任务状态。

## 状态优先级与边界

1. 同工具存在多会话：waiting > running > ended > idle；两个工具各自维护独立批次，旧完成历史不混入新批次。
2. 完成需要明确轮次完成信号；启动历史、文件没变化、进程消失、主动中断不是成功。
3. 已确认的完成不可被同一条旧记录再次弹出；新轮次能重新显示。
4. 回答与问题按调用 ID 和问题索引对应；部分回答不清空其他未答问题。
5. 读取失败不上传内容、不输出原始日志，最多保留活动 30 秒，然后空闲。已观察到的 Codex 待协助问题持续跟踪，不受普通任务的日志新鲜度窗口影响。
6. 锁屏隐藏窗口；显示器变化后按实际硬件重新定位。
7. 系统“减少动态效果”禁用装饰动画。
8. 客户端未安装时提示失败，不把失败跳转当作已查看。

## 人工验收

- 内置真实刘海及无刘海外接屏：空闲/运行/等待/完成分别截图，确认边界不抖动、不盖住摄像头。
- Claude 真任务与 Codex 真任务，双工具同时执行，核对动画及左右位置。
- 发起一个异步问题，等待至少一个扫描周期，回答后确认问号退出；多问题仅回答一项不得误退出。
- 多个会话完成后只查看其中一个，具体会话已读信号只清除对应项；单击或 Cmd-Tab 返回工具并持续前台约 1–2 秒，会清除该工具已有的完成提醒，但另一工具的提醒、运行中和待协助状态保留。
- Codex 本地未读列表移除对应线程、Claude 对应会话 lastFocusedAt 在完成后增长，才确认具体完成项已查看。这些具体会话信号缺失时，使用工具持续前台访问作为提醒消除规则。
- 校验菜单栏百分比与官方订阅页面同一时刻、同一窗口口径。
- 代理失效、未登录、401、429、锁屏、多屏切换均不崩溃。

自动测试不替代以上屏幕和真实账号验收。构建完成也不意味着已签名、公证或发布。

## v0.2 新用户与窗口规则

- 有实体刘海时优先使用内置刘海屏，状态条 y 等于屏幕顶部；使用非激活 panel 和 enableLargerThanScreen 避免 macOS 菜单栏约束下移。
- 展开内容放在摄像头下方，同一窗口中不存在第二条覆盖面板标题的状态条；悬停不展开，Escape / 失焦收起。
- 首次启动和再次打开应用进入居中的工具设置；所有开关立即生效、自动保存，不设保存按钮，关闭窗口后仍保留选择。Claude、Codex 分别开关并持久化，全部关闭后隐藏刘海，保留退出菜单栏图标；重新打开 Mac Notch 应用进入设置。
- UI 删除网络代理、sessionKey 输入；保留旧配置兼容。Claude 无登录时指导运行 CLI 并完成订阅登录，不承诺启动命令即一定有额度。
- 只读本地历史：日／周／月 Token、API 标准费率估算与按工具堆叠趋势。订阅剩余额度独立展示，不以 Token 反推。
